# Direção visual do GovIntel AI

## Conceito

O GovIntel AI é um centro de inteligência para licitações: calmo, preciso e orientado por evidências. A interface usa uma base de papel editorial, tipografia serifada para decisões e uma cor teal institucional para ações. O elemento memorável é a linha de evidência que conecta cada resultado, status e citação ao documento de origem.

## Princípios

- Mostrar contexto antes de decoração: documento, estado e fonte aparecem antes de ações secundárias.
- Usar contraste e espaço para indicar prioridade; cartões não devem virar uma grade de marketing.
- Manter ações reversíveis e estados assíncronos explícitos.
- Tratar citações como parte do produto, com página e trecho visíveis.
- Respeitar teclado, foco visível, leitura por leitor de tela e `prefers-reduced-motion`.

## Passes de implementação

1. Fundação: tokens, tipografia, foco, superfícies e cabeçalho compartilhado.
2. Fluxos: entrada, cadastro, dashboard, busca e chat com os mesmos estados semânticos.
3. Revisão: conferir os guias de tipografia, contraste, interação, movimento e UX writing antes da validação no navegador.
