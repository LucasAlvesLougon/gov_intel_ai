# Cor e contraste

- Papel: `#F4F0E8`; superfície: `#FFFDF8`; tinta: `#17212B`.
- Teal institucional: `#177E89`; sinal dourado: `#D6A84F`.
- Linhas: `#D8D2C8`; texto auxiliar: `#5D6870`.
- Texto normal e controles devem atingir pelo menos WCAG AA; a cor nunca é o único indicador de estado.
- Erros usam `#B5473C`, sucesso `#26734D` e processamento `#8A641D` com rótulo textual.
