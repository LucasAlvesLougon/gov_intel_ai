# Spec: delivery-operations

## Objective

Tornar CI/CD e deploy da demo reproduzíveis, verificáveis e apresentáveis. A infraestrutura local possui o módulo separado `local-infrastructure`.

## Acceptance Criteria

- README descreve setup do zero.
- CI executa lint, testes e build.
- Imagens Docker são reproduzíveis.
- Secrets são configurados por ambiente.
- Deploy escolhido é documentado com limitações.
